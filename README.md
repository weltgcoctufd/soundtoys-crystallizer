## Overview

Soundtoys Crystallizer creates shimmering, reverse-pitch, granular delay effects inspired by the Roland SDE-3000 processor, producing the classic 80s crystalline echo sound.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Soundtoys Crystallizer** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Reverse Mode** | Pitch-shifted reverse delay for ethereal shimmer effects |
| **Crystal Shift** | Adjustable pitch shift from -2 to +2 octaves per echo |
| **Grain Size** | Adjustable grain size shapes the granular character of the effect |
| **Mix Knob** | Wet/dry blend controls the intensity of the crystalline echo |
